## A propos de ce POC

Ce projet est un **proof of concept** pour valider la stack suivante :

- **Astro** pour la generation de site statique
- **TinaCMS** pour l'edition visuelle du contenu
- **TinaCloud** pour la synchronisation Git
- **GitHub Pages** pour l'hebergement

### Objectif

Evaluer cette stack avant de l'utiliser sur un vrai projet client (site vitrine).
